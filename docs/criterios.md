Criterios para clasificar recursos académicos

Los recursos académicos pueden clasificarse utilizando diferentes criterios.

1. Tipo

Permite identificar qué clase de recurso es.

Ejemplos:

 Libro
 Sitio web
 Video
 Artículo
 Software

2. Tema

Permite identificar el área o tema principal del recurso.

Ejemplos:

 Programación
 Matemáticas
 Redes
 Bases de datos
 Electrónica

3. Nivel académico

Permite identificar el nivel educativo para el cual es adecuado el recurso.

Ejemplos:

 Básico
 Medio superior
 Universitario
 Posgrado

 4. Autor o fuente

Permite identificar quién creó el recurso o cuál es la fuente de donde proviene.

Ejemplos:

 Autor de un libro
 Universidad
 Organización
 Sitio web especializado

5. Fecha de publicación

Permite identificar cuándo fue publicado o actualizado el recurso.

6. Idioma

Permite identificar el idioma en el que se encuentra disponible el recurso.

Estos criterios permiten organizar los recursos y facilitar posteriormente su búsqueda y consulta.
