Alcance del proyecto

El proyecto Catálogo de recursos académicos representa la estructura inicial de un sistema que posteriormente podría utilizarse para organizar y consultar diferentes recursos educativos.

Funcionalidades futuras

Registrar recursos: permitir agregar nuevos libros, sitios web, videos, artículos y herramientas de software.

Consultar recursos: permitir visualizar los recursos registrados en el catálogo.

Buscar recursos:  permitir realizar búsquedas por nombre, tema, autor o fuente.

Clasificar recursos: permitir organizar los recursos de acuerdo con diferentes criterios como tipo, tema y nivel académico.

Editar recursos: permitir modificar la información de un recurso registrado.

Eliminar recursos: permitir eliminar recursos que ya no sean necesarios.
